openSUSE es un proyecto global de código abierto con sede en Europa que desarrolla y distribuye sistemas operativos basados en Linux. El Proyecto openSUSE es un proyecto comunitario independiente que opera fuera del curso de cualquier actividad comercial. Las distribuciones de openSUSE son desarrolladas por colaboradores voluntarios y se ponen a disposición del público de forma gratuita, para promover el desarrollo de software de código abierto. El Proyecto openSUSE no es una empresa comercial y no pone productos en el mercado con fines comerciales.

SUSE Software Solutions Ireland Limited, una entidad establecida en Irlanda, actúa como administrador de software de código abierto proporcionando infraestructura, recursos y patrocinio para respaldar el proyecto openSUSE. openSUSE sirve como proyecto comunitario ascendente del que se derivan SUSE Linux Enterprise y otras ofertas empresariales comerciales de SUSE. Sin embargo, las distribuciones de openSUSE están separadas e independientes de las ofertas de productos empresariales comerciales de SUSE. SUSE Linux Enterprise se somete a un extenso proceso de desarrollo, prueba y certificación independiente antes de ofrecerse como un producto con soporte comercial. Las distribuciones de openSUSE cuentan con el respaldo de la comunidad openSUSE; no cuentan con soporte comercial de SUSE.

Este acuerdo regula su descarga, instalación o uso de las distribuciones de openSUSE y sus actualizaciones, independientemente del mecanismo de entrega. Las distribuciones de openSUSE son una obra colectiva. Al descargar, instalar o utilizar las distribuciones de openSUSE, acepta los términos de este acuerdo.

A efectos de este acuerdo, el término "las distribuciones de openSUSE" significa las distribuciones de software de código abierto puestas a disposición por The openSUSE Project y su comunidad sin coste alguno bajo las licencias de código abierto aplicables.

Las distribuciones de openSUSE son un sistema operativo Linux modular que consta de cientos de componentes de software. El acuerdo de licencia para cada componente generalmente se encuentra en el código fuente del componente. Con la posible excepción de ciertos archivos de firmware, los términos de licencia de los componentes le permiten copiar, modificar y redistribuir el componente, tanto en código fuente como en código binario.
